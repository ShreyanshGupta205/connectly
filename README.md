# Connectly ⚡ — One Profile. Every Connection.

**Connectly** is a modern, high-performance link-in-bio & interactive digital identity platform. It combines social link management, interactive high-contrast QR code studios, 1-click vCard (.vcf) contact saving, printable event posters, confetti like counters, and real-time live previewing.

---

## ✨ Features

- 🔗 **Smart Link Aggregator**: Add, edit, reorder, and toggle visibility of social links, portfolios, and projects.
- 📱 **Live Interactive Phone Mockup**: Real-time interactive preview of your profile with theme customization.
- 🎨 **Modern Themes**: Glassmorphism, Cyberpunk, Aurora Glow, Minimal Light/Dark, and Sunset gradients.
- 🔲 **QR Code Studio**: Customizable colors, rounded dots, embedded avatar badges, and instant PNG download.
- 📇 **1-Click vCard (.vcf) Export**: Direct contact saving to iOS & Android phonebooks.
- 🖨️ **Printable Event Posters**: Auto-generated high-resolution posters with scan frames & branding ready for print.
- 🎉 **Engagement & Analytics**: Interactive confetti like counter, link click tracking, and profile view stats.
- ⌨️ **Command Palette**: Press `Cmd+K` / `Ctrl+K` to search actions, switch profiles, and navigate instantly.

## 🚀 Quick Start (Local Development)

### 1. Install dependencies
```bash
npm install
```

### 2. Start the development server
```bash
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables & Animations
- **Icons**: Lucide React
- **QR Engine**: `qrcode.react`
- **Poster Rendering**: `html2canvas`
- **Celebration Effects**: `canvas-confetti`
